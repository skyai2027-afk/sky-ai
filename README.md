# Sky Fiori – מערכת אוטומטית למשפיענית AI 🤖

Sky Fiori היא דמות AI מקורית. המערכת מפרסמת בשמה 2 פוסטים ביום, אוטומטית לגמרי, ורצה בענן ב-GitHub. המחשב שלך לא צריך להיות דלוק.

## איך זה עובד

```
⏰ GitHub Actions מתעורר (10:00 ו-19:00)
→ 🧠 Gemini בוחר נושא וכותב כיתוב באנגלית + עברית (לפי persona.md)
→ 🎨 Cloudflare מייצר תמונה של Sky לפי תמונות הייחוס
→ 🔍 Gemini בודק שזו באמת Sky ושאין תקלות בתמונה (עד 3 ניסיונות)
→ 📤 פרסום: פייסבוק (+ אינסטגרם ו-Threads כשיחוברו)
→ 📲 טלגרם: עותק של הפוסט + קובץ מוכן לטיקטוק
```

**כל יום ראשון** ב-08:00 הבוט שואל בטלגרם מה הנושאים לשבוע. אם לא ענית עד 20:00, Sky בוחרת לבד.

## ✅ מצב אישור (פעיל)
לפני כל פוסט מגיעה בטלגרם תצוגה מקדימה, והפוסט עולה רק אחרי שאתה עונה:
| תשובה | מה קורה |
|---|---|
| `פרסם` / `/ok` / `כן` | הפוסט עולה |
| `דלג` / `/no` | הפוסט לא עולה |
| `תקן: ...` | Gemini כותב את הכיתוב מחדש לפי ההערה שלך, ומגיעה תצוגה מקדימה חדשה |
| `תמונה חדשה` | מייצר תמונה אחרת לאותו רעיון |

המערכת בודקת תשובות כל כחצי שעה. אם לא ענית תוך 12 שעות, הפוסט לא עולה.
כדי לכבות את מצב האישור, משנים בקובץ `config.json` את `"approval_mode": true` ל-`false`.

## 📸 תמונה משלך
שולחים לבוט תמונה, ואפשר להוסיף לה כיתוב קצר עם הסבר, למשל "בטיסה לברצלונה". היא נכנסת לתור ועולה בפוסט הבא, ו-Gemini כותב לה כיתוב.

## 📲 פקודות בטלגרם
| פקודה | מה היא עושה |
|---|---|
| `/pause` | עוצר את הפרסום (עד `/resume`) |
| `/resume` | מחזיר את הפרסום |
| `/status` | מצב המערכת והפוסט האחרון |
| כל הודעה אחרת | רעיון או עדכון שישמש בפוסט הבא, למשל "ברצלונה ניצחה 3-1" |

## ⏸️ איך עוצרים את המערכת
- **עצירה זמנית:** שולחים לבוט `/pause`.
- **עצירה מלאה:** ב-GitHub ← הלשונית **Actions** ← בוחרים **"Sky - daily posts"** ← כפתור **"..."** למעלה מימין ← **Disable workflow**. אותו דבר עבור **"Sky - weekly topics"**. מחזירים עם **Enable workflow**.
- **מתג ראשי:** בקובץ `config.json`, `"schedule_enabled": false` עוצר את כל הריצות המתוזמנות.

## 🕐 איך משנים את שעות הפרסום
בקובץ `.github/workflows/post.yml` יש שורה כזו:
```
- cron: "0 8,17 * * *"
```
השעות כתובות **בשעון UTC**. **שעון ישראל = UTC + 2 בחורף, ו-UTC + 3 בקיץ.**
- `8,17` = 10:00 ו-19:00 בחורף (11:00 ו-20:00 בקיץ)
- לדוגמה, ל-09:00 ול-21:00 בחורף כותבים `"0 7,19 * * *"`
- לפוסט אחד ביום כותבים שעה אחת, למשל `"0 17 * * *"`

אפשר לערוך את הקובץ ישירות באתר GitHub: פותחים אותו ← ✏️ ← משנים ← **Commit changes**.
GitHub לפעמים מאחר בכמה דקות עד חצי שעה בריצות מתוזמנות. זה תקין.

## ▶️ הרצה ידנית
GitHub ← **Actions** ← **"Sky - daily posts"** ← **Run workflow**:
- `test` = תצוגה מקדימה לטלגרם בלבד, שום דבר לא מתפרסם
- `post` = פרסום אמיתי עכשיו

## 🔑 מפתחות
כל המפתחות שמורים **רק** ב-GitHub ← Settings ← Secrets and variables ← Actions. הם לא נמצאים בקוד.
מפתח העמוד של פייסבוק לא פג, **אבל אם תשנה את סיסמת הפייסבוק של Sky הוא יתבטל**. במקרה כזה צריך ליצור אותו מחדש (`scripts/meta_setup.py`).

## 💰 עלויות
הכל חינמי: GitHub (repo ציבורי), Gemini (free tier), Cloudflare Workers AI (10,000 neurons ביום, בערך 12 תמונות), טלגרם ו-Meta API.
אם נגמרת המכסה היומית של התמונות, המערכת מדלגת על הפוסט ומודיעה בטלגרם. היא לא משלמת לבד, כי אין כרטיס אשראי באף שירות.
